# Historical project documents

These files describe earlier versions of the clinic application. They remain
useful for product history and design rationale, but their architecture,
commands, paths, tests, and deployment instructions are not authoritative for
the current repository.

Use the [project README](../../README.md) for the current entry point and
[docs/README.md](../../docs/README.md) for the current technical architecture.

- `BUILD.md` is the milestone log for the retired application.
- `GO_LIVE.md` is an obsolete cutover runbook.
- `HOSTING.md` records the original free-hosting analysis.
- `NEXT.md` is an old session handover.
- `PLAN.md` and `PROPOSAL.md` are pre-build product documents.
- `REVIEW.md` reviews documents that have since been superseded.
